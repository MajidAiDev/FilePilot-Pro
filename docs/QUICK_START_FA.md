# راهنمای شروع سریع FilePilot

## ۱. اجرای برنامه

1. اگر فایل ZIP را دریافت کرده‌اید، آن را در یک پوشه استخراج کنید.
2. روی ویندوز، فایل `install_dependencies.bat` را اجرا کنید تا وابستگی‌های لازم برای نمایش صحیح فارسی نصب و برنامه باز شود.
3. اگر نصب وابستگی‌ها به اینترنت دسترسی ندارد، فایل `run_filepilot.bat` را اجرا کنید؛ برنامه در حالت انگلیسی نیز کار می‌کند.

## ۲. اولین آزمایش، بدون ریسک

برای اولین اجرا، پوشه `demo_data` همراه پروژه را انتخاب کنید. این پوشه فقط حاوی فایل‌های ساختگی و بدون اطلاعات شخصی است.

1. روی «بررسی پوشه» بزنید.
2. در نمای کلی، تعداد فایل‌ها، حجم کل و دسته‌بندی‌ها را ببینید.
3. وارد «یافتن فایل‌های تکراری» شوید. دو فایل `meeting_notes.txt` و `meeting_notes_copy.txt` محتوای یکسان دارند و باید در یک گروه قرار بگیرند.
4. وارد «مرتب‌سازی امن» شوید و «ساخت پیش‌نمایش» را بزنید. برنامه فقط فایل‌های مستقیماً داخل پوشه انتخاب‌شده را برای انتقال پیشنهاد می‌کند؛ فایل‌های زیرپوشه جابه‌جا نمی‌شوند.
5. مقصدهای پیشنهادی را مرور کنید. اگر خواستید، جابه‌جایی فایل‌های نمونه را تأیید کنید.
6. برای آزمایش بازگردانی، از «بازگرداندن آخرین مرتب‌سازی» استفاده کنید. برنامه فایل موجود را در مسیر اصلی بازنویسی نمی‌کند.

## ۳. گزارش‌گیری

پس از اسکن، وارد «گزارش‌ها و خروجی‌ها» شوید. خروجی CSV، JSON یا HTML را انتخاب کنید. گزارش‌ها ممکن است مسیر کامل فایل‌های محلی را داشته باشند؛ پیش از ارسال برای دیگران آن‌ها را بررسی کنید.

## ۴. نکته ایمنی

اسکن فقط‌خواندنی است و فایل‌ها را حذف نمی‌کند. با این حال، اجرای مرتب‌سازی واقعاً فایل‌ها را جابه‌جا می‌کند. ابتدا روی `demo_data` آزمایش کنید و پیش از جابه‌جایی فایل‌های شخصی، پیش‌نمایش را با دقت بخوانید و از اطلاعات مهم پشتیبان داشته باشید.
